# 🌸 Memory Journal

*A little place for memories, thoughts and moments worth keeping.*

---

## 💗 About the Project

**Memory Journal** is a personalized digital diary developed to create a private, interactive and welcoming space for preserving personal memories and everyday experiences.

The project was designed around the idea of bringing different aspects of someone's life into one place, combining a simple interface with dedicated sections for writing, organizing and revisiting meaningful moments.

More than just a collection of notes, the goal is to create a digital space that feels personal, intuitive and enjoyable to use.

## ✨ Project Concept

The application is structured around a central dashboard, allowing users to navigate between different sections of their personal journal.

Each section has its own purpose and organization, providing a natural way to store different types of content.

Some of the planned sections include:

- **Thoughts:** A space for personal reflections and spontaneous ideas.
- **Memories:** A place to preserve meaningful experiences and special moments.
- **Hair:** A visual collection of hairstyles, inspirations and references.
- **Personal Notes:** A dedicated space for everyday notes and information.

## 📱 Design & User Experience

Memory Journal is designed exclusively for smartphone use, following a mobile-first development approach.

The interface prioritizes:

- Mobile-first layout and navigation.
- Touchscreen-friendly interactions.
- A personalized and welcoming visual identity.
- Simple and intuitive navigation.
- Dynamic content and interactive sections.
- An experience designed around smartphone screens.

|---|---|

| Technology | Purpose |
|---|---|

- Hosting the web application.
- Publishing project updates.
- GitHub integration for automatic deployments.

### 4. Version Control — Git & GitHub

- Source code storage.
- Version control and change tracking.
- Development history and project collaboration.

### 5. Android Conversion — Capacitor

- Reusing the existing web application code.
- Generating the Android project.
- Preparing APK/AAB builds for potential Google Play Store publication.
